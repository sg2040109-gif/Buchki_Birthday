BETU BIRTHDAY GIFT WEBSITE

1. Upload every file/folder in this package to a GitHub repository.
2. Keep the assets folder beside index.html.
3. On GitHub: Settings -> Pages -> Deploy from branch -> main -> /root -> Save.
4. Open the GitHub Pages link after deployment.

All 20 supplied photos are included. Four sideways photos were rotated before being placed in the gallery.
The site is mobile responsive and uses no external libraries.
